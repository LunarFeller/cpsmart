# cpsmart

cpsmart 是一个轻量的原生 macOS 菜单栏剪贴板历史工具。它在本机记录复制过的文本、图片和文件，按 `⇧⌘V` 会在当前屏幕底部弹出铺满当前显示器宽度的横向历史记录。

## 功能

- 自动记录文本、图片和文件复制历史
- 输入即过滤历史内容，搜索忽略大小写、变音符号和字符宽度
- 可按类型筛选历史（全部 / 文本 / 图片 / 文件，`⌘1`–`⌘4`）
- 图片记录显示经过后台解码和缓存的真实缩略图
- 打开后默认浏览历史，按 `Tab` 在卡片列表与搜索框之间切换
- 按空格键用 QuickLook 预览所选记录（图片大图、文本全文、文件内容）
- 记录并显示剪贴板内容的来源应用
- `⌘P` 置顶所选记录：置顶记录固定排在最前，清空和淘汰时自动保留
- `⇧⌘V` 全局快捷键呼出底部浮窗
- 深色 / 浅色 / 跟随系统三种外观，可在菜单栏「外观」中切换
- 单击卡片或按 `←` / `→` 才会选择并高亮，移动鼠标不会改变选择
- 双击卡片或按回车会返回原应用并自动执行 `⌘V`
- `Esc` 关闭（搜索时第一次 `Esc` 只清除搜索词），`⌘⌫` 删除所选记录
- 相同内容自动去重，最新记录排在最前
- 支持清空（保留置顶；菜单中按住 `⌥` 可连置顶一起清空）和暂停记录
- 历史默认最多 200 条、数据最多约 25 MB（可用 `defaults` 调整上限，也可按天数自动清理）；单张图片最大 8 MB
- 自动忽略密码管理器标记为隐藏、临时或自动生成的剪贴板内容
- 历史只保存在本机 `~/Library/Application Support/cpsmart/history.json`
- 可选“登录时启动”

## 安装

1. 打开 `dist/cpsmart-1.6.0-universal.dmg`。
2. 把 `cpsmart.app` 拖到 `Applications`。
3. 从“应用程序”启动 cpsmart，菜单栏会出现剪贴板图标。

当前构建使用 ad-hoc 本地签名，适合在本机安装。若要公开分发，需要 Apple Developer ID 证书并完成 notarization（公证）。

第一次使用“回车或双击直接粘贴”时，macOS 会请求“辅助功能”权限。请打开“系统设置 → 隐私与安全性 → 辅助功能”，点击列表下方的 `+`，从“应用程序”中选择 cpsmart 并打开右侧开关；该权限只用于向你原来所在的应用发送一次 `⌘V`。

当前安装包使用 ad-hoc 本地签名，重新构建后系统可能把它识别为新的程序。如果安装新版本后仍无法粘贴，请在上述“辅助功能”页面用 `−` 删除旧的 cpsmart，再用 `+` 重新添加 `/Applications/cpsmart.app`，随后完全退出并重新打开 cpsmart。正式分发需要使用稳定的 Developer ID 签名，才能避免频繁重新授权。

## 开发与构建

要求 macOS 13 或更高版本，以及 Apple Command Line Tools。无需完整 Xcode。

```bash
bash Scripts/run_tests.sh
bash Scripts/build_dmg.sh
```

构建脚本会分别编译 Intel 和 Apple Silicon 版本、合并为 Universal 2 应用，并在 `dist/` 生成 DMG。

## 隐私说明

剪贴板历史可能包含隐私信息。cpsmart 不联网、不上传历史，并会跳过带标准敏感标记的内容；但不是所有应用都会正确设置这些标记。处理敏感数据时，可从菜单栏选择“暂停记录”，并定期清空历史。
